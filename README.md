# 真练真会 · 408-practice

自用的 408 考研刷题工具。上传真题文档，AI 解析成题、人工审核后入库；做题分学习作答和考试作答；客观题自动判分，错题进错题本重做，学习时长和考试倒计时自动记，每道题右侧带一个 AI 伴读。

非商用，自己部署自己用：没有登录，没有多用户，数据只存在本机的 PostgreSQL 里，后端只监听 `127.0.0.1`。

## 功能

- **做题**：三栏布局（答题卡 / 题目 / 伴读），学习作答即时判分，考试作答倒计时、交卷后统一判分，考试中不显示答案。
- **错题本**：答完题可把题加入错题本，和普通卷分开练习、分开记录。
- **上传题目**：PDF、PNG、JPG、WEBP，AI 解析成结构化题目，逐题审核修改后入库。
- **个人记录**：考试记录（平均分、最高分、历次作答）和学习记录（进度、今日学习时长）。
- **伴读助手**：只针对当前题，引导和讲解两种模式，流式回复，对话按题保存。
- **设置**：OpenAI 兼容接口的地址、密钥、对话模型、视觉模型，密钥加密存库。

## 技术栈

| 位置 | 选型 |
|---|---|
| 前端 | React 18 + TypeScript + Vite + React Router + TanStack Query + Zustand |
| 后端 | Python 3.12 + FastAPI + SQLAlchemy 2.0 + LangGraph |
| 数据库 | PostgreSQL 16 |
| 模型调用 | OpenAI 兼容接口（地址、密钥、模型名在设置页填） |

## 数据库

需要本机有 PostgreSQL 16。建库后执行一次：

```bash
psql -U <用户名> -d <数据库名> -f db/schema.sql
```

脚本会建 12 张表并写入四条默认设置。重复执行不会覆盖已有数据。
